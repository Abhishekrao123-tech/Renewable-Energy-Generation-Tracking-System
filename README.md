\# EcoStream - Renewable Energy Generation Tracking System



\## Overview

EcoStream is a DBMS mini-project developed using Python and SQLite/MySQL to monitor, manage, and analyze renewable energy generation from Solar, Wind, and Hydro power sources.



\## Features

\- Energy source management

\- Generation tracking

\- Automated calculations

\- SQL queries and reports

\- Database normalization

\- CRUD operations



\## Technologies Used

\- Python

\- SQLite/MySQL

\- SQL

\- DBMS Concepts
